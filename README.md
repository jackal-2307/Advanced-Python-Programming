# Advanced-Python-Programming

Course materials, exercises, and Python solutions for Advanced Python
Programming. This repository will grow as more chapters, projects, and
exercises are added.

## Repository structure

- `Ly_thuyet/` contains lecture notes and course materials.
- `Thuc_hanh/` contains practical exercises, assignment PDFs, and solutions,
  organized by chapter.

New course materials and exercises can be added to the relevant folder as the
course continues.

## Running a solution

Run a Python exercise from the repository root with Python 3. For example:

```powershell
python Thuc_hanh/Chapter5/b1_student.py
```

Replace the example path with the script you want to run. Most exercise
scripts can be run on their own.
